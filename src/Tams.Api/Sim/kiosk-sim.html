    Fingerprint reader AS608, FR-1.3

    Fingerprint options and enrollment
    Staff starts a session, the kiosk idle poll picks it up, then Place finger and OK (confirm). The student must be enrolled first (a scenario does it for you).
    How matching works
    Default: the kiosk uploads the sensor image (TAMS-128): 256x288 raw 8-bit gray, base64, with width and height. The API builds a SourceAFIS template in memory, matches it 1:N against enrolled fingers, stores only the encrypted template and discards the image. The image here is a synthetic ridge pattern derived from student no. + finger index; Noise adds pixel noise and a small shift per scan. A match needs a SourceAFIS score of at least Kiosk:SourceAfisThreshold (provisional default 40, not calibrated on real AS608 captures). Untick "Send sensor image" for the legacy 512-byte template (Kiosk:MatchThreshold, Hamming distance, made-up bytes). Fingers enrolled one way only match the same way; delete and re-enroll to switch.
